变量与图标对照表

飞利浦风格控制面板 · 竖屏 1200×1920 · 底栏与读数区的每个图标都由 key=value 驱动。下表是「发什么值 → 屏幕变什么样」的完整契约。

1. 电池 —— bata / batb

bata = 球管 A 那行的电池（底栏第 1 行），batb = 球管 B 那行（第 2 行）。两条独立，互不影响。

00%（空）
125%（1 格）
250%（2 格）
375%（3 格）
4100%（4 格）
low低电告警
chg充电中
值图标含义说明
0
0%（空）电池空腔无填充
1
25%（1 格）
2
50%（2 格）
3
75%（3 格）
4
100%（4 格）设计稿默认帧
low
低电告警橙色 + 1 格，独立于电量数值
chg
充电中绿电池 + 白闪电（B 槽位主状态就是它）
参数范围：0 | 1 | 2 | 3 | 4 整数表示电量格数；另有三个关键字 chg（充电）、low（低电）、empty（等同 0）。
超出 0..4 的数字会被夹到边界（-1 → 0，9 → 4），不会报错也不会画空。
low 和 0 的区别：两者都是 1 格 / 0 格的电量，但 low 整只电池转橙色，用于告警；数字 0 是绿色空电池，只表示「电量为 0」。

2. 开口尺寸 —— det / detw / deth

底栏左上角那行文字（设计稿 "29 x 29 cm"）。横向、纵向是两个独立数，可以只改其中一个。

指令显示含义
det=3535 x 35 cm横纵一起设（正方形）
det=35x4335 x 43 cm一次给横向 35、纵向 43
detw=3535 x 43 cm只改横向；纵向保持当前值（示例假定纵向原来是 43）
deth=4335 x 43 cm只改纵向；横向保持当前值
注意：detw / deth 是「读当前值再改一个方向」，所以它们依赖上一次设过的值。上电初值是 29 x 29；网口那边如果每次都发全量，建议用 det=WxH 一条搞定，最不容易错。

3. 底栏图标状态

3.1 探测器 A / B（deta / detb）

取值图标状态说明
ready / 1 / on
就绪A 槽位默认就是蓝色（设计稿如此）
off / 0 / none
未就绪整只转灰
ready / 1 / on
就绪B 槽位要显式给 on 才变蓝
off / 0 / none
未就绪B 槽位默认就是灰色（设计稿如此）

3.2 栅格（grid / gridb）

取值图标状态说明
0
正常白色栅格；B 行带一个蓝色 i 标记
2
告警栅格转橙，蓝色 i 保留
0
正常
2
告警

3.3 准直器（collim）

取值图标状态说明
on / 1 / ok
打开白色框，设计稿默认
off / 0 / close
关闭整只转灰
warn / 2 / err
告警转橙

3.4 滤过（图标 filts，文字 filt）

取值图标状态说明
ok / 0 / on
正常白色滤过符号
warn / 1 / 2
告警转橙；文字用 filt="0.9 Cu + 1 Al" 单独下发

3.5 球管 A / B（tube）—— 联动 4 个图标

取值图标状态说明
A
A 在用A 方块蓝 + 绿箭头；B 方块与箭头同时转灰
B
B 在用B 方块蓝 + 绿箭头；A 侧转灰
tube 是唯一会同时改两组图标的变量：它把「本球管」那侧点亮、另一侧置灰，共 4 张图（ftBA / ftArrA / ftBB / ftArrB）。其它变量都只动自己那一个图标。

3.6 温度（tempa / tempb）

取值图标状态说明
< 70
正常绿柱；文字显示 "48°C" 这类实测值
≥ 70
告警红柱；阈值 kTempWarn=70，可改

3.7 HU 左侧温度计（hutemp）

取值图标状态说明
< 70
正常探测器温度，界面不显示数字，只靠颜色
≥ 70
告警与球管温度同一个阈值

3.8 剂量环（ring）

取值图标状态说明
ok / 0 / on
正常整圈绿
warn / 1 / 2
告警整圈红

4. 读数区（1×4，只有数值，没有状态图标）

变量图标设计稿初值说明
sid
115 cmReq.SID，只改数字，单位固定 cm
pheight
75 cm患者身高
angle
110°投照角度
standh
175 cm支架高度
读数区的数值是右对齐钉在单位左边：数字位数变化时向左生长，单位位置永远不动。所以 "115" → "5" 也不会错位。

5. 速查：一条指令测一个状态

指令效果
./dbg.sh set detw=35横向 35，纵向不动
./dbg.sh set deth=43纵向 43，横向不动
./dbg.sh set det=35x43横纵一次设完
./dbg.sh set bata=0A 电池空
./dbg.sh set bata=3A 电池 3 格
./dbg.sh set bata=lowA 电池橙色告警
./dbg.sh set bata=chgA 电池闪电动画位
./dbg.sh set batb=2B 电池 2 格（闪电消失）
./dbg.sh set tempa=75A 球管温度红柱
./dbg.sh set hutemp=75HU 左侧温度计转红
./dbg.sh set ring=warn剂量环转红
./dbg.sh set tube=B切到球管 B（A 侧置灰）
./dbg.sh set deta=off,detb=ready探测器状态互换

复位：./dbg.sh set reset=1 一次回到设计稿第一帧。
